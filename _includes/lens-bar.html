{% comment %} Lens: lets a visitor choose the angle from which to read a page. - Turn it on with `lens: true` in a page's front matter. - Wrap a section in
...
with blank lines inside the tags, naming the lenses it serves: engineer, physicist, mathematician, computational-scientist. - Untagged content is common to every lens. "All" shows everything. - Tag so that no lens shows a sentence whose reference it hides. The choice is remembered only in the visitor's own browser, and it can be shared as a link, for example ?lens=physicist. Without JavaScript the bar stays hidden and every section shows. {% endcomment %}
